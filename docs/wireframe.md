# 📱 마이링크 (MyLink) 메인 화면 와이어프레임 명세

> **대상 화면:** 방문자가 보는 단일 모바일 프로필 화면 (Public Profile Page)  
> **기준 디자인 시스템:** 토스 디자인 시스템 (TDS)  
> **최대 레이아웃 폭:** `max-w-md` (약 420px 모바일 뷰포트 중심)

## 2. 세부 컴포넌트 계층 명세

### 2.1 상단 프로필 헤더 (Profile Header)
- **아바타 이미지**: 80px × 80px 원형 컨테이너 (`rounded-full`), 그라디언트 링 테두리, 우하단 온라인 표시 그린 뱃지
- **이름 (Name)**: `text-lg font-bold text-grey-900`, 우측에 공식 인증/체크 마크 아이콘
- **상태 뱃지 (Status Badge)**: `bg-blue-50 text-blue-600 rounded-full px-2.5 py-0.5 text-xs`, 내부에 작은 블루 도트
- **자기소개 (Bio)**: `text-xs text-grey-600 leading-relaxed max-w-[280px]`, 중앙 정렬
- **소셜 아이콘 바 (Social Icons)**: 36px × 36px 원형 버튼 4~5개, 호버 시 명도 전환

### 2.2 섹션 구분 헤더 (Section Divider)
- **스타일**: 좌측 볼드 소제목 (`text-[11px] font-bold text-grey-400 uppercase tracking-wider`) + 우측 1px 디바이더 선(`bg-grey-100`)

### 2.3 URL 링크 카드 (Link Cards)
- **스타일**: 풀 위드 둥근 카드 (`rounded-2xl border border-grey-200 bg-white p-4 shadow-2xs`)
- **인터랙션**: 호버 시 `border-blue-400 shadow-md translate-y-[-1px]` 상승 인터랙션
- **내부 요소**:
  - 좌측: 40px × 40px 아이콘 컨테이너 (`rounded-xl`)
  - 중앙: 타이틀 (`text-sm font-bold text-grey-900`) + 서브 설명 (`text-[11px] text-grey-500`)
  - 우측: `ChevronRight` 화살표 (`text-grey-400 group-hover:text-blue-600 transition`)

### 2.4 푸터 (Footer)
- **스타일**: 중앙 정렬, 캡슐형 "마이링크로 나만의 페이지 만들기" CTA 버튼 및 카피라이트 표기
